# crawler-labs · 爬虫攻防靶场教程

> 零基础 Python 爬虫教程 · 12 个攻防回合 · **从裸爬到工程化，全程有对手**。

这不是又一本爬虫语法手册。你将对着一个**可反复重置的练习靶场**逐级升级：
裸爬 → 身份伪装 → 限速退避 → 识破蜜罐 → 浏览器渲染 → Scrapy 工程化 →
打真实网站 → 反过来写防护。每学一个函数就动手用一次。

## 三步开始（按你的情况选）

| 步骤 | 适合谁 | 做什么 |
|---|---|---|
| **① 零安装试玩** | 还没装 Python，先看看这是不是你的菜 | 打开 [第 1 章 · 浏览器版](interactive/ch01.html)，网页里直接跑 Python |
| **② 部署练习靶场** | 决定往下学（第 3 章前完成） | clone 本仓库与 [crawler-dojo](https://github.com/djdj45-SSH/crawler-dojo)，`python -m server.main --level none` 起靶场 |
| **③ 跟课文走** | 所有人 | 从 [第 1 章 · 你的第一次请求](ch01.md) 开始，每章末尾用 `python main.py --chapter N` 过关 |

试玩版与真实环境的差异会在每个试玩页里写明；**第 4 章起，浏览器版覆盖不了，
必须回到本地环境**——这不是偷懒，是因为"改 User-Agent、控制限速节奏"这些事，
浏览器在安全层面就不允许。
